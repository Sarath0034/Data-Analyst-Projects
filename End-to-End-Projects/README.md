# End-to-End Data Analytics Projects

This folder contains complete data analytics projects that combine multiple tools such as Python, SQL, Power BI, Tableau, machine learning, forecasting, and data visualization libraries.

## Projects

| Project | Description | Tools |
| --- | --- | --- |
| [Crypto Market Analytics Dashboard](Crypto-Market-Analytics-Dashboard) | End-to-end cryptocurrency market analysis using API data, Python cleaning, SQL EDA, Tableau dashboarding, Power BI reporting, and visual analytics. | Python, SQL, Power BI, Tableau, Pandas, Matplotlib, Seaborn |
| [Financial Fraud Detection & Transaction Intelligence](Financial-Fraud-Detection-main/Financial-Fraud-Detection-main) | End-to-end financial fraud analytics using transaction data, Python feature engineering, advanced MySQL analysis, anomaly detection, fraud classification, risk scoring, and a Power BI investigation dashboard. | Python, MySQL, SQL, Pandas, NumPy, Scikit-learn, imbalanced-learn, Power BI, DAX |
| [Hotel Demand & Revenue Intelligence Dashboard](Hotel-Demand-and-Revenue-Intelligence-Dashboard-main/Hotel-Demand-and-Revenue-Intelligence-Dashboard-main) | End-to-end hotel analytics and demand forecasting covering booking patterns, cancellations, customer behavior, anomaly detection, time-series forecasting, machine learning, and interactive Power BI dashboards. | Python, SQL, Pandas, NumPy, Isolation Forest, SARIMA, Random Forest, Scikit-learn, Statsmodels, Power BI, Power Query, DAX ||
