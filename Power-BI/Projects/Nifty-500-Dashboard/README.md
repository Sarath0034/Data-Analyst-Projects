# Nifty 500 Dashboard

This Power BI project is an interactive financial analytics dashboard for the Nifty 500 index. It helps users quickly explore quarterly results and understand company-level performance across important financial metrics.

## Dashboard Highlights

- Company-wise financial results including EPS, net profit, taxes, operating profit, and TTM profit
- Net profit, operating profit, and trailing twelve months profit analysis
- Financial distribution and revenue share visualizations
- KPI cards for growth and performance tracking
- Smooth navigation between Home and Dashboard pages

## Data Source

The dashboard uses financial data from Nifty 500 companies, including EPS, net profit, operating profit, taxes, TTM profit, total operating expenses, and related quarterly financial report metrics.

## Tools and Technology

- Power BI Desktop for dashboard development
- DAX for calculated measures and KPIs
- Data modeling for efficient analysis
- Interactive charts and dashboard navigation
