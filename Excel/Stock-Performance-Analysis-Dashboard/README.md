# Stock Performance Analysis Dashboard

This Excel project analyzes stock performance for leading technology companies: Apple (AAPL), Amazon (AMZN), Facebook (FB), Google (GOOGL), and Microsoft (MSFT).

The dashboard visualizes market trends and trading performance using dynamic charts, filters, and summary metrics. It is designed to turn raw stock data into clear investment-focused insights.

## Key Insights Covered

- Stock-wise beta values and P/E ratios
- Market capitalization comparison across companies
- Average daily traded volume visualization
- 52-week high and low deviation analysis
- Buy and sell signals based on short-term indicators such as RSI and MACD

## Tools and Skills Used

- Microsoft Excel
- Pivot tables
- Data modeling
- Conditional formatting
- Interactive charts
- Dynamic dashboard design
- Financial data visualization
- Trend analysis
