# Database Case Study Projects

This folder contains SQL database case study projects across different business domains. Each file demonstrates database design, relational querying, and practical analysis for a real-world style system.

| --- | --- | --- |

| Employee Payroll Promotion System | [employee_payroll_promotion_system.sql](employee_payroll_promotion_system.sql) | Employee records, payroll, promotions, HR tracking, and workforce data. |

| Hospital Appointment Database | [hospital_appointment_database.sql](hospital_appointment_database.sql) | Patients, doctors, appointments, healthcare scheduling, and hospital records. |
| Bank Transaction Fraud Detection | [bank_transaction_fraud_detection.sql](bank_transaction_fraud_detection.sql) | Banking transactions, fraud indicators, and risk-focused SQL analysis. |
