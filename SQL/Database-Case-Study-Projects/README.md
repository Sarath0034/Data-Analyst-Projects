# Database Case Study Projects

This folder contains SQL database case study projects across different business domains. Each project is built around a realistic dataset structure and demonstrates SQL database design, investigation queries, reporting logic, and analysis techniques.

## Projects

| Project | SQL File | Description | SQL Concepts |
| --- | --- | --- | --- |
| Project 01: E-Commerce Order Investigation | [ecommerce_order_investigation.sql](ecommerce_order_investigation.sql) | Customers, orders, products, payments, and shipping for a full retail funnel. | `JOIN`, `CTE`, `CASE WHEN` |
| Project 02: Bank Transaction Fraud Detection | [bank_transaction_fraud_detection.sql](bank_transaction_fraud_detection.sql) | Accounts, merchants, and locations built for spotting suspicious timing patterns. | Window functions, `LAG`, `LEAD`, self joins |
| Project 03: Hospital Appointment Database | [hospital_appointment_database.sql](hospital_appointment_database.sql) | Patients, doctors, and departments for missed visits, doctor load, and appointment history analysis. | Joins, CTEs, date logic |
| Project 04: Airline Booking Analysis | [airline_booking_analysis.sql](airline_booking_analysis.sql) | Passengers, flights, and routes for demand, booking, route, and cancellation analysis. | Ranking, CTEs, multi-join queries |
| Project 05: Social Media Database | [social_media_database.sql](social_media_database.sql) | Users, posts, likes, follows, and messages for engagement and network analysis. | Self joins, set operations, window functions |
| Project 06: Employee Payroll and Promotion | [employee_payroll_promotion_system.sql](employee_payroll_promotion_system.sql) | Salary history, promotions, and reviews across a realistic reporting hierarchy. | `RANK()`, self joins, subqueries |
| Project 07: Food Delivery Order System | [food_delivery_order_system.sql](food_delivery_order_system.sql) | Customers, restaurants, drivers, and deliveries modeled end to end. | CTEs, nested queries, date/time logic |
| Project 08: Automotive Service Center | [automotive_service_center_database.sql](automotive_service_center_database.sql) | Multi-location vehicle service history, technicians, and revenue analysis. | Ranking, `CASE WHEN`, conditional aggregation |

## Skills Demonstrated

- SQL database design and table relationships
- Business case modeling across multiple domains
- Joins, CTEs, subqueries, and self joins
- Window functions such as `RANK()`, `LAG()`, and `LEAD()`
- Conditional logic with `CASE WHEN`
- Date and time analysis
- Conditional aggregation and KPI-style reporting
- Data investigation and insight generation
